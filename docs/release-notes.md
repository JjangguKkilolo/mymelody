# 마이멜로디 연습 친구 1.1.0

기존 9종을 서로 다른 도트 의상으로 리메이크하고, 양·계란 친구를 추가했습니다. 이제 총 11종을 만날 수 있어요.

- 도트 윤곽과 부드러운 색감을 유지하면서 의상·귀 모양·자세·소품을 다양하게 바꿨습니다.
- 딸기는 씨앗 무늬의 딸기 모자와 크림 장식으로, 정원은 민트 체크무늬 옷으로, 비 오는 날은 구름무늬 우비로 새로 꾸몄습니다.
- 양은 복슬복슬한 양옷과 실뭉치, 계란은 동그란 알에서 깨어나는 세 단계 모습으로 자랍니다.
- 11종 모두 세 단계 성장과 눈 깜빡임을 제공합니다. 12·24·36시간 성장 기준은 같습니다.
- 기존 연습 기록·경험치·컬렉션·설정과 30분 세션 표시 규칙을 유지합니다. 이미 완성한 친구도 새 외형으로 표시됩니다.
- 기존 9종을 모두 완성했다면 새 두 친구만 중복 없이 이어서 뽑을 수 있습니다.
