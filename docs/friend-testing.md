# 친구에게 부탁하는 5분 테스트

Windows PC와 MIDI 건반, Cakewalk가 있으면 아래 순서로 확인해 주세요.

1. [최신 릴리스](https://github.com/JjangguKkilolo/mymelody/releases/latest)의 `MyMelodyPractice-win-Portable.zip`을 폴더 전체로 풀고 **마이멜로디 연습 친구.exe**를 실행합니다. .NET SDK 설치는 필요 없습니다.
2. **첫 친구 만나기**를 누르고, **설정 → 연습 입력**에서 연결된 건반을 선택합니다.
3. 1분 정도 연주하며 홈 화면의 오늘 연습 시간이 늘고 캐릭터가 반응하는지 확인합니다.
4. Cakewalk도 열어 같은 MIDI 건반으로 연주합니다. 소리·입력에 문제가 없는지 확인합니다. 앱을 먼저 실행했을 때와 Cakewalk를 먼저 실행했을 때 각각 확인해 주세요.
5. 연주를 멈추고 35초 기다립니다. 처음 30초만 여유 시간으로 기록되고 그 뒤 시간이 멈춰야 합니다.
6. 건반을 다시 누르면 기록이 재개되는지, USB를 뽑으면 기록이 멈추고 다시 연결한 후 새 연주로 재개되는지 확인합니다.
7. 캐릭터를 숨겨도 기록되는지, 크기·위치 변경 후 재시작해도 유지되는지 확인합니다. 앱을 완전히 종료하려면 트레이 메뉴의 **종료**를 누릅니다.
8. 설정에서 백업을 내보내고 복원한 뒤 캐릭터와 기록이 유지되는지 확인합니다.

## 알려주면 좋은 결과

- Windows 버전, 건반 모델, 사용한 MIDI 드라이버, Cakewalk 버전
- 앱과 Cakewalk를 동시에 켰을 때 입력·소리가 정상인지
- 자동 측정·정지·재연결이 정상인지
- 실행 오류가 있다면 오류 문구와 저장 폴더의 `error.log`

시간이 있다면 설정의 **Windows 시작 시 자동 실행**을 켠 후 다시 로그인했을 때 캐릭터와 트레이가 나타나는지도 확인해 주세요.
