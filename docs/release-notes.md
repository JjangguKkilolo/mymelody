# 마이멜로디 연습 친구 1.3.2

달력을 앱에 어울리는 분홍색 연습 다이어리로 다듬었어요. 연습한 시간이 길수록 날짜의 분홍색이 짙어져요.

- 달력의 날짜 칸과 월 이동 버튼, 누적 연습 표시를 하나의 둥근 카드로 정리했습니다.
- 기록이 없는 날은 흰색, 연습한 날은 시간에 따라 점점 진한 분홍색으로 표시합니다. 하루 4시간 이상은 가장 진한 색이며, 어느 달이든 같은 시간을 같은 색으로 보여줍니다.
- 하루 선택은 하트와 진한 테두리, 조회 기간은 테두리로 표시해 연습량 색상과 구분합니다. 날짜 위에 마우스를 올리면 해당 날짜의 연습 시간을 볼 수 있습니다.
- 시작일·종료일 입력창과 펼쳐지는 작은 달력도 분홍색 테마로 바꿨습니다. 날짜를 직접 입력하거나 월·년을 이동해 고를 수 있습니다.
- ‘오늘’ 버튼으로 현재 날짜에 바로 돌아갈 수 있습니다. 연습 기록을 열 때 오늘만 보여주는 동작과 기간 조회, 입력 중인 날짜 유지도 그대로 제공합니다.
- 기존 연습 기록·경험치·수집 상태·설정과 캐릭터 그림체·크기를 유지합니다.
