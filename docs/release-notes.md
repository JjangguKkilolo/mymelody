# 마이멜로디 연습 친구 1.3.0

도감에서 이전 성장 모습을 다시 보고, 마음에 드는 단계를 바탕화면 캐릭터로 설정할 수 있어요.

- 2단계까지 키운 친구는 1·2단계, 3단계까지 키운 친구는 1·2·3단계 모습을 고를 수 있습니다. 아직 도달하지 않은 단계는 잠겨 있어요.
- 컬렉션에서 단계를 골라 미리 본 뒤 ‘N단계로 표시’를 누르면 그 모습으로 고정합니다.
- ‘성장에 맞춰 표시’를 누르면 현재 모습을 표시하고, 성장할 때 자동으로 새 모습으로 바꿉니다.
- 이전 모습을 표시하거나 완성한 친구를 꺼내 두어도 현재 친구의 육성과 연습 기록은 계속 쌓입니다.
- 선택한 모습은 재시작·백업 복원·업데이트 후에도 유지됩니다. 새 친구를 뽑으면 새 친구를 성장에 맞춰 표시합니다.
- 기존 기록·경험치·수집 상태·설정을 유지하며, 12종의 그림체와 표시 크기도 그대로입니다.
