# 마이멜로디 연습 친구 1.2.0

분홍 공룡 코스튬을 입은 마이멜로디가 새로 왔어요. 이제 총 12종을 만날 수 있습니다.

- 기존 도트 그림체와 부드러운 색감을 유지한 공룡 친구를 추가했습니다.
- 작은 꼬리와 공룡 모자에서 시작해, 리본·등 장식·알 소품이 더해지는 세 단계로 성장합니다. 눈 깜빡임도 포함합니다.
- 공룡도 기존 친구들과 같은 높이·바닥선으로 표시합니다. 새 캐릭터가 늘어나도 기존 친구들의 크기가 변하지 않도록 표시 기준을 고정했습니다.
- 기존 11종을 모두 완성했다면 공룡을 바로 뽑을 수 있습니다. 미완성 친구가 있다면 먼저 성장을 마치면 됩니다.
- 기존 그림 원본·연습 기록·경험치·수집 상태·설정은 그대로 유지됩니다.
