# 마이멜로디 연습 친구 1.3.1

연습 기록을 열면 오늘 기록부터 보여주고, 원하는 날짜 구간도 조회할 수 있어요. 캐릭터가 화면 밖으로 사라지지 않도록 위치 보정도 개선했습니다.

- ‘연습 기록’을 열 때마다 현재 날짜의 기록만 표시합니다. 오늘 모드에서 자정이 지나도 새 날짜로 맞춥니다.
- 시작일·종료일을 고르고 ‘기간 조회’를 누르면 두 날짜를 포함한 구간의 기록만 표시합니다. 비어 있거나 앞뒤가 바뀐 날짜는 기존 조회를 유지한 채 안내합니다.
- 달력에서 하루를 누르면 그날만 보여주고, 같은 날짜를 다시 눌러도 선택이 유지됩니다. 하루 선택은 체크 표시로, 기간 조회는 연한 배경으로 구분합니다.
- 세션 목록 위에 조회 날짜와 세션 수를 표시합니다. 새 기록이 없으면 자동 갱신 때도 기존 목록과 날짜 버튼을 유지합니다.
- 캐릭터를 놓거나 드래그 캡처를 잃으면 실제 모니터의 작업 영역 안으로 돌아옵니다. 위아래·좌우와 작업표시줄, 여러 모니터 사이의 빈 공간을 고려합니다.
- 크기·화면 배치가 바뀌거나 앱을 다시 켤 때도 캐릭터가 보이는 위치로 보정합니다.
- 기존 기록·경험치·수집 상태·표시 단계와 그림체·크기는 유지합니다.
