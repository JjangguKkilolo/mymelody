# 마이멜로디 연습 친구 1.0.1

짧게 쉬었다 다시 연주할 때 연습 기록이 여러 줄로 잘게 나뉘던 표시를 개선했습니다.

- 같은 날짜·같은 기록 방식의 연습 구간은 휴식이 30분 미만이면 한 세션으로 표시합니다.
- 30분 이상 쉬거나 날짜·기록 방식이 바뀌면 새 세션으로 나눕니다.
- 이미 저장된 23초·30초 같은 짧은 기록에도 적용합니다.
- 인정 시간과 음표 수는 원래 기록을 합산하며, 쉬는 시간에 경험치를 추가하지 않습니다.
- 기존 기록 원본·캐릭터·성장 상태·설정을 보존합니다. 저장 형식은 바꾸지 않으며, 설치 전 자동 백업도 유지합니다.
