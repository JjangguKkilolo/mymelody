# 검증

## 자동 테스트

```powershell
dotnet test MyMelody.slnx -c Release
```

Core 테스트는 가상 시계로 성장 경계, 중복 없는 뽑기, 수동·자동 전환, 30초 유예, 자정 분할, 잠금/절전과 동등한 suspend, 시계 변경, 저장 실패 재시도, 5초 자동 저장, 일일 백업, 손상·지원하지 않는 백업, 시작 시 DB 복구를 검증합니다.

Update 테스트는 읽기 전용 확인, 사용자가 요청한 다운로드, 중복 작업 방지, 정식 신규 버전 판정, 취소·검증 오류·재시도, MIDI 메시지 필터를 검증합니다.

2026년 9월 14일 기준 Core 22개, Update·MIDI 25개, 총 47개를 통과했습니다.

1.0.1에서는 세션 표시의 30분 경계, 기존 원본 불변, 날짜·수동/자동 경계, 재시작·백업복원 후 보존을 확인하는 테스트 12개를 추가했습니다. Core 34개와 Update·MIDI 25개, 총 59개를 통과했으며, 화면 검사에서도 23초와 30초 기록이 인정 시간 53초인 한 세션으로 표시되는지 확인합니다. 데이터베이스 구조와 저장된 연습 구간은 변경하지 않습니다.

## 실제 업데이트

`tests/MyMelody.UpdateSmoke`는 개인 저장과 다른 패키지 ID로 두 시험 버전을 만들고 실제 Velopack 프로세스로 업데이트·재시작합니다. 13시간 연습, 캐릭터·설정, 업데이트 전 백업이 유지되는지 검증합니다. 설치형과 포터블을 모두 검사합니다.

1.0.1 변경 검증에서는 기존 1.0.0 시험 패키지를 다시 빌드하지 않고 보존한 채, 새 Core를 포함한 1.0.1로 업데이트했습니다. 설치형과 포터블 모두에서 원시 세션 ID·시각·인정 시간·음표 수·기록 방식과 캐릭터·설정의 정확한 일치, 업데이트 전 백업 복원을 확인했습니다.

## 화면 렌더링

```powershell
dotnet run --project src/MyMelody.App -c Release -- --ui-smoke artifacts/ui-qa
```

이 모드는 지정한 출력 폴더 아래 새 시험 데이터 폴더를 만들고 개인 기록·실제 MIDI·자동 실행 설정을 사용하지 않습니다. 실제 WPF 화면을 100·150·200%로 렌더링하며 27개 에셋을 확인합니다. 시험 기록은 실제 연습으로 제시하지 않습니다.

GitHub Actions와 패키징 스크립트도 이 검사를 실행합니다. 투명 배경과 두 표정 프레임을 갖춘 PNG 27개, 최소 창 크기, 모든 페이지, 백업 왕복 검사를 통과해야 배포할 수 있습니다.

1.0.2부터는 앱 ICO의 9개 크기(16–256픽셀), 창·트레이 로딩, 실행 파일의 아이콘 리소스도 확인합니다. 같은 아이콘을 밝은 배경과 어두운 배경에 실제 크기로 렌더링한 `icons-preview.png`를 검사 결과 폴더에 저장합니다.

## 실제 장비와 환경

사용자에게 MIDI 건반이 없어 실제 건반·Cakewalk 동시 연주 검증은 친구가 진행하기로 했습니다. [테스트 안내](friend-testing.md)를 사용하세요. 물리 디스플레이 DPI 변경과 깨끗한 SDK 미설치 Windows VM도 별도 확인 항목입니다. 자동 테스트 또는 번들 런타임 확인을 이 장비 검증의 대체로 표시하지 않습니다.
